# Protection

`protection.sh` — интерактивный bash-скрипт для администрирования Ubuntu/Debian серверов (~2880 строк, 62 функции). Скрипт помогает быстро настроить SSH, пользователей, UFW firewall, Fail2ban и Docker, а также сохранить параметры конфигурации в `/root/info.txt`.

> **Внимание**: скрипт меняет системные настройки сервера. Запускайте его только на сервере, к которому у вас есть резервный способ доступа (отдельный SSH-ключ, консоль, VNC).

## Возможности

- изменение пароля `root`;
- создание пользователей и настройка SSH-ключей (добавление новых и использование существующих);
- включение/отключение аутентификации по SSH-ключам;
- изменение SSH-порта;
- включение/отключение входа `root` по SSH;
- включение/отключение ответа на ICMP ping;
- включение/отключение IPv6;
- установка и управление Fail2ban (конфигурация, добавление jails);
- настройка и управление UFW firewall (добавление/удаление портов);
- установка, обновление и обслуживание Docker;
- автоматическое создание глобальной команды `protection`;
- сохранение конфигурации в `/root/info.txt`.

## Требования

- Ubuntu или Debian;
- запуск от `root`;
- доступ к интернету для установки пакетов;
- `sudo` необязателен: если он установлен, скрипт использует его, иначе выполняет команды напрямую от `root`.

## Установка

Скачайте скрипт на сервер:

```bash
sudo curl -fsSL -o protection.sh https://raw.githubusercontent.com/svu2009-prog/Protection/main/protection.sh
sudo chmod +x protection.sh
```

Запустите:

```bash
sudo ./protection.sh
```

При запуске скрипт создаёт или обновляет глобальную команду:

```bash
/usr/local/bin/protection
```

Команда устанавливается копированием самого скрипта в `/usr/local/bin/protection`, без символической ссылки и без wrapper-файла. Если установленная версия совпадает с текущей, файл не перезаписывается. Если установленная версия старее, она заменяется новой копией.

После первого запуска можно использовать:

```bash
sudo protection
```

Проверить версию:

```bash
sudo protection --version
```

## Главное меню

Основное меню открывается при запуске `sudo protection` или `sudo ./protection.sh` и содержит:

1. Обновить пакеты;
2. Поменять пароль ROOT;
3. Поменять порт SSH;
4. Управление пользователями;
5. Отключить/включить доступ к команде PING;
6. Отключить/включить IPv6;
7. Настроить SSH-ключи;
8. Настроить, отключить/включить Fail2ban;
9. Настроить, отключить/включить Firewall UFW;
10. Отключить/включить вход ROOT по SSH;
11. Docker;
12. Справка;
0. Выйти.

## Важные предупреждения

- Перед изменением SSH-порта убедитесь, что новый порт открыт в firewall и у вас есть активная сессия.
- Перед включением UFW проверьте, что текущий SSH-порт разрешён.
- Полное удаление Docker удаляет данные Docker из `/var/lib/docker`.
- Ошибочная настройка SSH-ключей или `PermitRootLogin` может привести к потере доступа.
- Файл `/root/info.txt` содержит несекретные параметры, например SSH-порт и имя созданного пользователя; пароли скрипт в него не записывает.

## Обновление

Скачайте свежую версию `protection.sh` и запустите её:

```bash
sudo curl -fsSL -o protection.sh https://raw.githubusercontent.com/svu2009-prog/Protection/main/protection.sh
sudo chmod +x protection.sh
sudo ./protection.sh
```

Если глобальная команда `/usr/local/bin/protection` старее скачанного скрипта, она будет заменена новой копией.
